# Repository guidance

This repository is the source of truth for the game. Do not rely on an earlier chat for current story or asset state.

## Before editing

- Run `npm run context -- --route <route-id> --node <node-id>` for node-specific work.
- Read the route's `content/routes/<route-id>/context.md` for continuity rules.
- Read `PROJECT_STATE.md` for the current milestone and pending decisions.
- There is one playable story entry; character branches join the default package via `storyFiles` and in-story choices, not a title-screen route selector.
- Keep node IDs and logical asset IDs stable. Changing image paths must not require engine changes.

## Source and generated files

- Edit `content/`, `src/`, `dist/index.html`, and `dist/styles.css` as sources.
- All `dist/*.js` and `dist/content/routes/` files are generated by `npm run build`; do not edit them directly.
- Final image and video assets live in `dist/assets/` and must have matching manifest and recipe entries.

## Required verification

- Run `npm run build`, `npm run validate`, and `git diff --check` after changes.
- Run `npm test` for runtime/save changes; check title → continue, node resume, and branch restart in the browser.
- Finish and push one verified milestone, then stop and report. Use a low-cost publishing subagent when available. Never force-push.
- If a model usage limit interrupts work, pause and retry after 30 minutes; a user-confirmed reset allows an immediate retry.
- A route may only use assets listed in its `assetIds`.
- CG and cinematic nodes cannot also declare composite fields.
- Character design, outfit, hairstyle, and makeup versions must match their asset dependencies.

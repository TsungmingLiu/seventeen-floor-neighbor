## 四種不同的戀愛體驗

| 角色 | 主要魅力 | 關係成長的核心 |
| --- | --- | --- |
| 許棠 | 日常默契、不明說的偏愛、細微幽默 | 從鄰里日常走到願意讓對方真正參與自己的生活 |
| 江雨澄 | 同頻後的私人世界、創作／遊戲主場、熟後靈動吐槽 | 從興趣交集走到主動分享內在世界與感情需要 |
| 林若晴 | 玩伴感、主動邀請、小勝負心、一起行動與出糗 | 從一起玩得開心走到特別想把時間留給對方，也學會確認彼此步調 |
| 沈映雪 | 初戀重逢中熟悉與陌生的交錯、成熟而明確的欣賞 | 從舊熟悉重新認識現在的彼此，重建信任並重新決定未來 |

四人可以共享「會笑、會主動、會安靜、會犯錯」等正常人的特質；差異在於她們最自然的反應、建立親密的方法，以及必須面對的關係課題。不要靠職業、髮型或單一口頭禪代替人物差異。

## Relationship baseline

- 許棠與江雨澄的現行 knowledge／crossover 以既有 narrative artifacts 為準。
- 林若晴由羽球團獨立認識男主；與其他女主沒有預設既有關係。
- 沈映雪與男主曾在大學成年時期正式交往，畢業後因工作異地、長期缺乏可持續的共同生活安排而分開；成年後重逢。重逢不等於自動復合。
- 新角色與其他女主若未來產生關係，必須由實際 narrative event 建立，不從人物總表自動獲得 knowledge。

# Archived production documents

> Lifecycle: **ARCHIVED — NOT A PRODUCTION SOURCE OF TRUTH**

這裡保存已退出現行 production policy 的歷史文件，供 provenance、migration 與 decision archaeology 使用。

- Fresh worker 不得把本目錄加入 `allowed_sources`。
- Active harness 不得引用本目錄。
- 歷史 asset ID、scene intent 或 runtime fixture provenance 只有在 migration/research task 明確指定時才可讀。
- Archive 中的 prompt、aspect ratio、sprite/background pipeline、batch workflow 都不可直接執行。

移入 archive 不代表刪除 runtime capability 或 binary fixture；它只表示該文件不再決定新的 production work。

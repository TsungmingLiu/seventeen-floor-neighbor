## Scene-local progression

1. 捷運出口碰面。許棠比平常稍有準備；普通早期熟人同行，不做盛裝或浪漫揭示。
2. 進店時本來只想看一本設計書，卻停在另一區的攝影集。男主觀察她翻頁、停留；自己的小行程與當下步調開始不一致。
3. 看書超過男主預想後設一組 **action choice**，選擇具體行為而非 stance；不要求 Warm/Candid/Playful，也不以人格標籤顯示。保留必要等待與普通接話，讓分歧有現場原因。
4. 各分支先完成下表的局部互動，再以收起書、確認眼前是否繼續看或離店的合理橋接回共同收束。共同段不倒灌分支才取得的頁面知識。
5. 原本下一站的重要性逐漸降低。許棠自己提出附近找地方喝東西；本次短坐是同一 outing continuation，各路保留自己的舒適或拘束程度。
6. 喝東西的短 continuation 完成、結束這次相處後才記一次 major investment 與 slot consumption。未 produced successor 以工具 preview boundary 停止，不在玩家 narration 宣告故事完成或下一幕已接受。

## Action consequences and rejoin

下列為 intent metadata，待 dialogue worker 寫玩家可見 action wording；沒有成稿台詞。

| Action intent | Immediate consequence | Rejoin / memory |
| --- | --- | --- |
| 留下陪她慢慢翻看 | 她自然把感興趣的書頁轉過來；男主有機會回應自己看見的細節 | `xt_respected_pace=true` 僅記具體一起慢看與書頁分享（Echo）。不授予浪漫或未來 scene gate。 |

| 用輕鬆方式處理等待 | 以她停留很久作當地玩笑；她可普通回應、乾式接話或沒完全接住 | Local 反應後接回當下看書／收書，不宣告既有 inside joke 或以幽默解鎖後續。 |

本輪不另設普通 expression choice。若 dialogue pass 確有自然需要，可在不改上述 action/effects 的位置設 exactly 3 個合理 Warm/Candid/Playful expression options，各一次且 UI 隱藏 stance，僅 Local/Echo，不控制後續可達 scene 集合。
